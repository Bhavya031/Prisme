Means weight each scored prediction equally. Spend is a token × list-price estimate (see Setup), not a provider invoice.

**Time (benchmark):** per-prediction time is the NeatLogs trace latency of the prediction's workflow span (model calls plus Entire searches; issue-context collection ran before the span). 13 of 120 traces return HTTP 404 from the NeatLogs read API, so they have no time. Total wall time: 1728 s (28.8 min) from the first prediction's start to the last one's end, 120 predictions run one at a time. Stored per prediction as `neatlogs_timing` in the JSON.

**Speed (live workflow):** GitHub Actions runs of *Prism automated estimation and allocation* on [Bhavya031/flask](https://github.com/Bhavya031/flask/actions) triggered by an opened issue took 167–187 s from run start to finish; the run posts the estimate comment, allocates in CFO.ai and reports the allocation on the issue (runs 38526742471, 38527311380, 38527854554 on 2026-10-14; `gh run list -R Bhavya031/flask`). This is the live bot, not the benchmark runner.

## Setup

- **Claude `claude-sonnet-5-5`** via Anthropic Messages API: effort `medium`, max 4000 output tokens per call, strict JSON-schema output, up to 1 extra search round (`pipeline.predict(ctx, provider, max_extra=1)`).
- **OpenAI `gpt-6-sol`** via OpenAI Responses API: effort `medium`, max 4000 output tokens per call, strict JSON-schema output, up to 1 extra search round (`pipeline.predict(ctx, provider, max_extra=1)`).
- **Search:** Entire code search only, no git fallback. Each model proposes literal terms; every term runs as `entire search --code --repo gh/prism-benchmarks/<name> --json --limit 30 -- <term>` ([`src/prism/entire.py`](src/prism/entire.py)). Hits outside the snapshot's file tree are dropped.
- **Entire repos:** `gh/prism-benchmarks/flask` @ [`ad68a12645d9`](https://github.com/prism-benchmarks/flask/tree/ad68a12645d96fe51558da13e18544ba458d7af0), `gh/prism-benchmarks/requests` @ [`70298332899f`](https://github.com/prism-benchmarks/requests/tree/70298332899f25826e35e42f8d83425124f755a5), `gh/prism-benchmarks/click` @ [`047adef258fc`](https://github.com/prism-benchmarks/click/tree/047adef258fc25566163ffc3efd14effc0ef7352), `gh/prism-benchmarks/pytest` @ [`3b17fa79f8ad`](https://github.com/prism-benchmarks/pytest/tree/3b17fa79f8ad28bbda7aa468a750605be9c24553), `gh/prism-benchmarks/pydantic` @ [`f512b087202f`](https://github.com/prism-benchmarks/pydantic/tree/f512b087202f58ec90a9d38c9102858567d72440). Before any paid call, each snapshot repo's `main` had to equal its SHA and `entire repo view` had to report ready.
- **Issue context:** issue text, plus comments and referenced items created before the fix PR was opened; lines that mention the fix PR are removed.
- **Ground truth:** files the fix PR lists with status `modified` that exist in the snapshot tree (`github_context.true_files`); added and deleted files are not counted.
- **Scoring per prediction:** recall = |predicted ∩ truth| / |truth|; precision = |predicted ∩ truth| / |predicted| (0 when nothing is predicted); exact = predicted set equals truth.
- **Cost:** per call, (uncached input × input price + cached input × cached price + cache writes × cache-write price + output × output price) / 1M, with `models.PRICES` (USD per 1M tokens): `claude-sonnet-5-5` input 2.0, cached 0.1, cache write 2.5, output 10.0; `gpt-6-sol` input 2.0, cached 0.2, cache write 2.5, output 10.0. Claude input tokens exclude cache reads; OpenAI cached tokens are subtracted from input. Reasoning tokens are part of output.
- **Caps:** $2.00 per model for the whole run. Before each call the runner refused to send if spend so far plus a conservative bound ((prompt + system + schema bytes + 10k) × $2.5/M + max output × $10/M) would cross the cap.
- **Tracing:** every prediction ran inside one NeatLogs workflow span; 120 unique trace IDs are recorded.
- **Runner:** [`scripts/entire_benchmark.py`](scripts/entire_benchmark.py), the script that produced the raw results, kept as run (its paths point at the machine it ran on). The flask #3193 exclusion and the `summary` block were added to the JSON afterwards ([701c860](https://github.com/Bhavya031/Prisme/commit/701c860bb0ea0a6d8abbaca2b212c641e1ce7edf), [006ec9f](https://github.com/Bhavya031/Prisme/commit/006ec9fc166608b2575de54130cf3fe2052f1015)).

**Reproduce** (spends real model credit; edit `ROOT`, the `.env` path and the Entire token path at the top of the runner first):

```sh

git checkout main -- scripts/entire_benchmark.py

git checkout main && python scripts/benchmark_page.py  # rewrite this page
```
